Store & Search

Encrypted vault with fuzzy search. Add keys with provider auto-detection for 20+ services. Find anything instantly.

$ kf add OPENAI_API_KEY sk-xxx --provider openai
✓ Stored OPENAI_API_KEY (openai)

$ kf search resend
Found 1 match: RESEND_API_KEY (resend)

Per-Project Keys

Same env var, different values per project. Inject the right keys automatically with kf run.

$ kf add DATABASE_URL postgres://dev:5432 --projects dev-app
$ kf add DATABASE_URL postgres://prod:5432 --projects prod-app

$ kf run --project dev-app -- npm start
✓ Injected 12 keys into dev-app

Cloud Sync

End-to-end encrypted sync across machines. The server never sees plaintext. Deploy your own sync worker to Cloudflare.

$ kf sync init
✓ Registered and bound to cloud

$ kf sync push
✓ Pushed 47 keys (E2E encrypted)

Military-Grade Security

AES-256-GCM encryption, Argon2 key derivation. Runtime injection means plaintext never hits disk. Lock your vault instantly.

# Secrets injected at runtime, never written to disk
$ kf run --project myapp -- npm start

# Lock vault instantly
$ kf lock
✓ Vault locked. Passphrase cleared.
MCP Compatible

AI reads your vault.
Never your secrets.

Built-in MCP server exposes metadata only — name, provider, project, status. Your AI coding assistant discovers and uses keys without ever seeing the secret value.

  • One command: kf setup claude
  • Works with Claude, Cursor, Windsurf, Gemini, Codex, Zed, and more
  • 10 tools: discover, inspect, reuse, maintain
MCP setup
$ kf setup claude
✓ MCP configured for Claude Code

# Your AI assistant now has access to:
• search_keys — find keys by keyword
• get_key_info — metadata (never plaintext)
• list_projects — discover project scopes
• check_health — vault hygiene report
• get_env_snippet — masked .env for project

Get started in seconds

Pick your install method. Then kf init to create your vault.

Homebrew (recommended)
$ brew tap nianyi778/keyflow && brew install keyflow
Cargo (from source)
$ cargo install --git https://github.com/nianyi778/keyflow
Quickstart
$ kf init                                # Create vault
$ kf add OPENAI_API_KEY sk-xxx --provider openai  # Store a key
$ kf search openai                        # Find it fast
$ kf run --project myapp -- npm start       # Inject & run
